# 咨询逐字稿（Android · 全程离线）

把心理咨询会谈录音，在手机本地转成可编辑、自动区分说话人的文字逐字稿。
**不联网、不上传、不保存录音（除非明确同意）、无需登录**——为咨询师的小范围自用与分发而做。

## 📲 我是咨询师，只想直接用

直接到本仓库的 **Releases** 页面下载最新的 `咨询逐字稿-...apk`，传到安卓手机安装即可。
安装与使用的**一页纸说明见 [咨询师安装说明.md](咨询师安装说明.md)**。

**最重要的三条**
1. 不联网：`AndroidManifest.xml` 里没有声明 `INTERNET` 权限，连第三方库带进来的 `ACCESS_NETWORK_STATE` 也已剔除，系统层面断死外传。
2. 默认不保存录音：成稿后自动覆写删除原始录音，只有来访者明确同意才保留，且可随时删除。
3. 来访者只用代号，不存真实姓名；导出文件只含文字。

## 本机自用版的两点简化（v1.0.1）

按使用者要求，这两项已**彻底去掉**，打开 App 直接进入首页，数据安全由使用者自行负责：

- **无进入锁**：删除了人脸/指纹/密码验证页，不再有「验证后进入」，装好点开即用。
- **不加密存储**：逐字稿以明文 SQLite 存在 App 私有目录（`consult.db`）。已移除 SQLCipher、Keystore、BiometricPrompt 相关代码与依赖，包体更小。注意：明文数据 root 后可读、不在加密之列，请勿把手机交给不可信的人。

## v1.0.2 真机 bug 修复（历史）

1. **首次授权后闪退**：改为「权限授予成功后才启动录音服务」，不再异步竞态开录音；录音服务加了异常兜底。
2. **逐字稿里一堆孤零零的「。」**：过滤掉只有标点/噪声、没有实际文字的识别段。
3. **「说话人 A 是谁」弹窗点了没反应**：改用响应式数据，点选后立即生效。

## v1.0.5 导入录音（支持在线咨询，当前版本）

1. **首页点「导入录音」**，选一个已有的录音文件（mp3/m4a/wav/aac 等），填代号、选人数，即可在本机转成逐字稿。文件只在手机里处理，不联网、不上传。
2. **在线咨询怎么用**：微信电话本身没有录音；普通 App 也拿不到微信/电话的双方实时声音（系统权限限制 + 戴耳机对方声音不进麦克风）。所以正确做法是——**先用腾讯会议/飞书自带录制、手机系统通话录音，或另一台录音笔，存下一份双方清晰的音频，再导入本 App** 转文字。
3. 导入后走的和现场录音完全一样的流程：多人分人、角色全局/单段编辑、人工校对、导出 TXT 全都能用。
4. 默认不保留导入音频（源文件本来就在你手机里）；需要时可在导入页勾选保留。

## v1.0.4 多人识别 + 角色编辑（历史版本）

1. **支持 2/3/4 人**：新建咨询时先选人数。婚姻咨询选 3 人（咨询师+丈夫+妻子），家庭咨询选 4 人。系统按人数自动分出 A/B/C/D。
2. **首次逐个指定角色**：转写完进逐字稿，弹窗让你给每个说话人选角色（预设：咨询师/来访者/丈夫/妻子/父亲/母亲/孩子/其他，也能自己填）。选一次全篇套用。
3. **改一个、全篇跟着变**：顶部「角色对应」可随时重开映射；两个人叫反了点「一键对调 A/B」，整篇立刻换过来。
4. **个别句子单独改**：点任意一段 → 选角色，只改这一段，不影响全篇。低置信度段有浅黄底提示复核。
5. **旧记录不受影响**：数据库自动升级，之前录的两人逐字稿照常能看、能导出。
6. **诚实提醒**：人越多越可能分错（音色像、抢话、孩子声音小）。它出的是初稿，务必人工校对一遍再导出。

## v1.0.3 防杀后台 + 全程全录（历史版本）

1. **全程全录、小声不漏**：录音从头到尾连续采集，不启用「静音跳过」。小声说话、叹气、哭腔都会录进去（代价是文件不因静音而变小）。想停时按「暂停」即可。
2. **四层防杀后台**：前台服务常驻通知 → 录音期间持有 CPU 唤醒锁（锁屏/切后台不断） → 万一被系统杀掉会自动重启并**接着上次继续录**（文件追加、计时不归零） → 设置页可一键把 App 加入电池优化白名单。
3. **强烈建议做一次设置**：首次使用进「设置 → 后台保活」，点「一键加入白名单」。华为/小米/OPPO/vivo 还要在「设置 → 应用 → 自启动/后台」里允许本 App 后台运行，长时录音最稳。
4. **不会开机偷偷录音**：手机重启后不会自动开麦克风；重启只会恢复「没转写完的文字任务」，隐私可控。

## 在自己电脑上复现构建

```bash
cd ConsultTranscript
# local.properties 写你的 sdk.dir；key.properties 指向你的签名密钥
./gradlew assembleRelease
# 产物 app/build/outputs/apk/release/app-release.apk
# 验证零联网：aapt dump permissions <apk> | grep -i internet  应无输出
```

工程已自带 `gradlew` / wrapper 并预置 Gradle 8.9 发行包，首次构建无需联网下载 Gradle。
模型与 AAR 已随源码放好，无需再下载。

## 三个诚实边界

1. 小模型不是出版级逐字稿，专业词/方言/抢话会出错字，**人工校对省不掉**（界面每段可改）。
2. 沙箱无真机，完成的是编译/打包/签名/静态验证全通过，**运行时链路未实机跑过**，装真机请先走一遍短录音验收。
3. 签名用本地自签测试证书，仅用于可直接安装测试；对外分发请自管密钥并核对 SenseVoice 的 FunASR 许可署名要求。
